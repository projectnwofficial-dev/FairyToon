- `FairyToon.shader`: lilToon property names / defaults and Forward, Outline, ShadowCaster, CharacterShadow, DepthOnly, DepthNormals, MotionVectors, SeeThroughMask, SeeThroughFakeShadow, SeeThroughEarlyZ and SeeThroughHair passes.
- `FairyToonInput.hlsl`: unconditional `UnityPerMaterial`, textures, gated UV0..UV3 context, Main Color 2nd / 3rd (decal / MSDF / blend / alpha), UV animation, base color / alpha mask / clipping.
- `FairyToonNormals.hlsl`: shared first / second normal decoding; second-normal map selects raw UV0..UV3 and its own transform, while its scale mask uses transformed main UV0 and its own transform. Tangent-space XY add and Z multiply as in lilToon; world-space normalization follows in Forward / SeeThroughHair / DepthNormals.
- `FairyToonAnisotropy.hlsl`: canonical tangent-direction map / signed scale, masked shift noise, two highlight lobes and independent Reflection / MatCap / MatCap 2nd routes. Degenerate tangent-projection fallbacks, finite zero-width lobes and a bounded sharp-toon AA threshold.
- `FairyToonGlitter.hlsl`: procedural particle pattern, UV0 / UV1 placement, independent UV0..UV3 color map, optional shape texture / transform / `_GlitterAtras`, randomized size / rotation, both packed parameter vectors, lighting / shadow / backface masks and transparency. Desktop view-direction blend retains `_GlitterVRParallaxStrength`; XR has not been tested. Transparent alpha is applied once; zero-alpha sparkle is suppressed, unmasked inverse-alpha gain is capped at 4096 (alpha floor 1/4096), and float RGB is clamped to +/-65504 before half conversion, including HDR.
- `FairyToonCore.hlsl`: toon diffuse / face SDF / Forward+ lights / SH / SSAO, Backlight, Reflection, MatCap, Rim Light / Shade, both animated emissions, shared Anisotropy / Glitter hooks.
- `FairyToonEndfield.hlsl`: Endfield shading (`_FT_ENDFIELD`); keeps shared main layers, normals, Backlight, Reflection, MatCap, Rim, Glitter and emission. Cloth / metal keep isotropic Endfield GGX unless active Reflection specular owns the anisotropic highlight, when Endfield direct specular is suppressed. `_Anisotropy2Reflection` alone never replaces Endfield GGX. Custom Skin / Face / Hair / Eye highlights remain. Optional 0.3.0 P0+P1 additions (all default 0 / no-op): `_ShadowBorderMask.r` AO fallback when `_PBRMap` is absent, Multi-Bounce colored AO (`_EFMultiBounceAO`), 6-tap character-depth Contact AO (`_EFContactAO`), screen-space Curvature (`_EFCurvature`), cloth/metal environment contrast + metal grazing tint (`_EFEnvContrast`, `_EFMetalGrazingColor`), microfiber Fabric Sheen (`_EFFabricSheen`), and Clearcoat (`_EFClearcoat`). Backlight uses Endfield's normalized direct main color times day strength, without ambient / top fill; Backlight receives scene shadows only (raw in toon mode as in lilToon, `_ShadowReceive`-scaled in Endfield).
- `FairyToonPasses.hlsl`: vertex / fragment programs and consistent combined normals.
- `FairyToonSeeThrough.hlsl`: face mask, early Z and fake-shadow coverage.
- `FairyToonRefraction.shader`, `FairyToonFur.shader`, `FairyToonGem.shader`: separate heavy rendering shaders with the complete main property contract and matching lilToon special properties. Common property defaults and Gamma attributes follow the parity-fixed main shader; the special pass topology remains separate.
- `FairyToonVariantInput.hlsl`: per-shader material-buffer extension through default-empty `FT_VARIANT_PROPERTIES`; identical in every pass of each special shader, with existing material samplers reused.
- `FairyToonVariants.hlsl`: shared optical surface setup, roughness-driven nine-tap opaque-scene blur and gem dispersion / environment / particles. Optics precede MatCap / Rim / Glitter / emissions. Refraction outputs composed RGB with alpha one. Gem uses a minimal black/fog PRE and additive final contributions, so interior faces accumulate.
- `FairyToonFur.hlsl`: separate geometry stage, conditional layer UVs and VS-to-GS-only direction / vertex-ID data. Barycentric ribbons reproduce lilToon's density 1–3 strip, noise / root taper / cutout and AO. Main light + SH only on Endfield ribbons; full shared body shading. Body-only auxiliary passes; no Metal geometry support.

Texture properties whose `_ST` is consumed by HLSL expose scale / offset in all four material shaders; `[NoScaleOffset]` remains on textures sampled without independent transforms. The custom material inspector follows the same property flags. `_Metallic` / `_Reflectance` retain `[Gamma]`: directly authored slider values follow lilToon sRGB semantics (Linear uploads: 0.5 -> about 0.214, 0.04 -> about 0.0031), with no automatic migration or rescaling.

Refraction/Gem need URP Opaque Texture (PC: enabled, 2x downsampling). Other transparents are absent from that copy. Refraction defaults to queue 2900 / ZWrite On and preserves authored depth. Blur preserves lilToon Blur2's smoothness/depth LOD relation with nine taps because URP's opaque copy has no mip chain. Refraction applies the shared `_SmoothnessTex_ST` after main UV; Gem retains its source bare main-UV sampling. Optical roughness includes routed anisotropy once, before GSAA.

Gem defaults to queue 2900 / Cull Off / ZWrite Off: GemPre (SRPDefaultUnlit) writes black One/Zero and scene fog once, then Forward (UniversalForward) adds all faces One/One with fog towards black. Authored Cull/ZWrite survive conversion. Fur uses body SRPDefaultUnlit, fur UniversalForward, optional second fur UniversalForwardOnly. Transparent / 2 Pass body uses straight-alpha SrcAlpha/OneMinusSrcAlpha equivalent to lilToon's premultiplied body; every mode writes body depth and enables body auxiliaries. Cutout and 2 Pass shell PRE use AlphaToMask; blended tips do not. Toon shells use geometric-normal shadow, rim shade and fur rim only; Endfield uses main light + SH + rims. Both use source light-color inverse lighting. Source auxiliary dithering / extra subpass clipping and DepthOnly root-noise coverage remain approximations.

Forward / Forward+ only; actual draw order and visuals remain unverified without Unity. Touch collision and legacy ForwardAdd settings are retained but inactive in URP. No special shader has See-through Hair passes; Fur and Gem reserve the outline tag for body/PRE and preserve dormant outline values. Full imported-property and limitation lists are in the package README; offline evidence is in [Tests~/VariantsReport.md](../Tests~/VariantsReport.md).

Main layers share `_FT_MAIN_LAYERS` in Forward and body coverage; emissions share `_FT_EMISSION` in Forward / SeeThroughHair. Normal Map 2nd and Glitter use mutually exclusive off / UV0 / extra-UV groups: `_FT_NORMAL2ND` vs `_FT_NORMAL2ND_UV`, and `_FT_GLITTER` vs `_FT_GLITTER_UV`. Extra-UV alternatives normalize to the existing feature macros in Input. Both stages see these groups in the color passes; only Normal Map 2nd also has DepthNormals variants. Anisotropy / Backlight are fragment-only. Outline has no new feature variants; the motion hull keeps base alpha / mask.

Mesh inputs and interpolators are explicitly gated. UV0-only Normal Map 2nd / Glitter add none when main layers / emission are off. Extra-UV variants add TEXCOORD8 float4 + TEXCOORD9 float2. Main layers / emission retain that UV1..UV3 pair. DepthNormals normal-only uses zero added geometry; clipped main layers add only TEXCOORD11 world position, reusing normalWS / tangentWS.w. Other clipped main-layer coverage uses the UV pair plus TEXCOORD10 normal / handedness and TEXCOORD11 position. Outline / motion hull and coverage without clipped main layers add none. Uniform UV selectors cannot strip VS interfaces: the two existing binary feature groups become three alternatives, with no independent dimension (Forward 16 -> 36 VS / 64 -> 144 PS combinations in the documented subset, DepthNormals 4 -> 6). Reapply MaterialSetup for existing materials and runtime UV0/nonzero changes.

Forward decal edges use mapped saturated N.V; coverage uses geometric N.V, Emission Rim absolute N.V. Both emission masks use raw UV0 and their transforms. Transparent Rim, MatCap / MatCap 2nd and Reflection specular / environment use `FairyToonTransparentBlend`: P = alpha*C; deltas Normal S-P, Add S, Screen max(S-P*S,0), Multiply P*(S-1). Apply Transparency on uses C + mask*delta; off compensates by inverse alpha with the same 4096 cap and half-range clamp as Glitter. Opaque / cutout call the original blend; alpha=1 is unchanged in all modes. Emission retains its division-free conversion. All constants remain unconditional and material samplers are shared; custom cubes use the parity trilinear sampler. The package README contains the full interface table and numeric limits.

Earlier main-shader baseline: 25 Node checks and 94 DX11 VS/PS pairs pass, including all-feature Cutout / Transparent matrices; feature-off and second-normal UV0 / extra-UV Opaque passes; both mixed Normal Map 2nd / Glitter UV layouts; isolated Glitter UV0 / extra UV; Endfield anisotropy with Reflection off; body MotionVectors; emission-only interfaces; and Transparent Endfield probe atlas / volumes. Actual VS signatures, constant-buffer layout and the 16-sampler limit are checked. The Cutout resource counts remain 42 / 44 / 45 / 48 / 46 / 42 PS textures and 10 PS samplers for Toon / Cloth / Skin / Face / Hair / Eye; probe variant 52 / 11. DepthNormals normal-only uses 2 textures / 1 sampler. Full configurations and the per-pass context table are in the package README. Unity import, actual SRP Batcher operation, screenshots / visual comparison, Vulkan / XR, native-half execution and the Unity 6000.6.0f1 Editor remain untested; Unity was not launched. Current merged-tree checks and standalone Editor C# compilation are recorded in [Tests~/MergeConsistencyReport.md](../Tests~/MergeConsistencyReport.md); Tests~/VariantsReport.md is historical pre-merge evidence.

Refraction uses shared facing normals and final BackfaceColor after optics, with unit alpha to avoid a second coverage division. Gem keeps its single interior-normal adjustment; Fur strands keep geometric normals before layer coverage. Their body/optical shared layers use the corrected MatCap mask transforms, third shadows and reflection color/lighting. Gem environment sampling reuses the shared cube helpers and Gamma/Linear formulas. Every pass includes the same unconditional common buffer plus its shader-specific extension; no material constants were duplicated.

Forward, Refraction/Gem and Fur shells share `FairyToonForwardSurface`; ordinary and optical shading share `FairyToonShadeBase` through Rim Shade, diffuse/additional lights, unlit main layers and Backlight. Post-optical layers retain their framebuffer-alpha treatment. Endfield faces both lighting normals independently of `_FlipNormal`; Toon keeps lilToon facing and Gem keeps its interior tilt. DepthNormals always faces the mapped normal. Reflection/Gem sample URP probes with world position and screen UV, so Forward+ never falls back merely because `unity_SpecCube0` is unbound.
